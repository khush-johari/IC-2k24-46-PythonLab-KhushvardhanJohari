SNIPPET 1 — Find Maximum


Code:

def find_max(arr):
    max_val = arr[0]
    for i in range(1, len(arr)):
        if arr[i] > max_val:
            max_val = arr[i]
    return max_val

Time complexity: O(n)
Space complexity: O(1)

Justify: The loop checks every element once, while only a single variable max_val is used.


SNIPPET 2 — Check Duplicate


Code:

def has_duplicate(arr):
    for i in range(len(arr)):
        for j in range(i + 1, len(arr)):
            if arr[i] == arr[j]:
                return True
    return False

Time complexity: O(n²)
Space complexity: O(1)

Justify: Two nested loops compare pairs of elements, resulting in roughly n × n comparisons.


SNIPPET 3 — Sum of Digits


Code:

def sum_digits(n):
    if n == 0:
        return 0
    return n % 10 + sum_digits(n // 10)

Time complexity: O(log n)
Space complexity: O(log n)

Justify: Each recursive call removes one digit by dividing n by 10, and the recursive call stack stores one frame per digit.


SNIPPET 4 — Print/Store All Pairs


Code:

def print_pairs(arr):
    n = len(arr)
    result = []
    for i in range(n):
        for j in range(n):
            result.append((arr[i], arr[j]))
    return result

Time complexity: O(n²)
Space complexity: O(n²)

Justify: The nested loops generate n² pairs, and the result list stores all n² pairs.


SNIPPET 5 — Binary Search


Code:

def binary_search(arr, target):
    low, high = 0, len(arr) - 1
    while low <= high:
        mid = (low + high) // 2
        if arr[mid] == target:
            return mid
        elif arr[mid] < target:
            low = mid + 1
        else:
            high = mid - 1
    return -1

Time complexity: O(log n)
Space complexity: O(1)

Justify: Each iteration eliminates approximately half of the remaining elements, while only a few variables are used.


SNIPPET 6 — Matrix Multiplication


Code:

def matrix_multiply(a, b):
    n = len(a)
    result = [[0] * n for _ in range(n)]
    for i in range(n):
        for j in range(n):
            for k in range(n):
                result[i][j] += a[i][k] * b[k][j]
    return result

Time complexity: O(n³)
Space complexity: O(n²)

Justify: Three nested loops each run n times, while the n × n result matrix requires O(n²) space.


SNIPPET 7 — Convert Matrix to Sparse Representation


Code:

def to_sparse(matrix):
    triples = []
    for r in range(len(matrix)):
        for c in range(len(matrix[0])):
            if matrix[r][c] != 0:
                triples.append((r, c, matrix[r][c]))
    return triples

Time complexity: O(mn)
Space complexity: O(k)

Justify: Every one of the m × n matrix elements is examined, while only the k non-zero elements are stored.

def process(arr):

    for i in range(n):
        print(arr[i])
    for j in range(n):

Justify: The first loop takes O(n) and the nested loops take O(n²); therefore O(n + n²) simplifies to O(n²).

def check_first_ten(arr):

SNIPPET 10 — Reverse Using a New List


Code:

def reverse_new(arr):
    reversed_arr = []
    for i in range(len(arr) - 1, -1, -1):
        reversed_arr.append(arr[i])
    return reversed_arr

Time complexity: O(n)
Space complexity: O(n)

Justify: Every element is copied once into a new list, requiring linear time and linear additional space.


SNIPPET 11 — Reverse In-Place


Code:

def reverse_in_place(arr):
    left, right = 0, len(arr) - 1
    while left < right:
        arr[left], arr[right] = arr[right], arr[left]
        left += 1
        right -= 1
    return arr

Time complexity: O(n)
Space complexity: O(1)

Justify: The loop performs about n/2 swaps, which is O(n), and no additional data structure is created.


SNIPPET 12 — Recursive Factorial


Code:

def factorial(n):
    if n == 0 or n == 1:
        return 1
    return n * factorial(n - 1)

Time complexity: O(n)
Space complexity: O(n)

Justify: The function makes n recursive calls, creating a recursion stack of depth n.


SNIPPET 13 — Recursive Fibonacci


Code:

def fibonacci(n):
    if n <= 1:
        return n
    return fibonacci(n - 1) + fibonacci(n - 2)

Time complexity: O(2^n)
Space complexity: O(n)

Justify: Each call branches into two recursive calls, producing exponential time, while the maximum recursion depth is n.

Note: More precisely, the time complexity is often written as O(phi^n), where phi ≈ 1.618, but O(2^n) is the standard Big-O answer for this activity.


SNIPPET 14 — Count Pairs Using a Set


Code:

def count_pairs_with_sum(arr, target):
    seen = set()
    count = 0
    for num in arr:
        if target - num in seen:
            count += 1
        seen.add(num)
    return count

Time complexity: O(n) average
Space complexity: O(n)

Justify: Each element is processed once and set lookup/insertion is O(1) on average, while the set can contain up to n elements.


SNIPPET 15 — Generate All Subsets


Code:

def print_all_subsets(arr):
    n = len(arr)
    for i in range(2 ** n):
        subset = []
        for j in range(n):
            if i & (1 << j):
                subset.append(arr[j])
        print(subset)

Time complexity: O(n × 2^n)
Space complexity: O(n) auxiliary space

Justify: There are 2^n subsets and up to n elements are checked for each subset; the temporary subset contains at most n elements.

Note: If the complete output is counted, printing all subsets requires O(n × 2^n) output space.


SNIPPET 16 — Merge Two Sorted Arrays


Code:

def merge_sorted(a, b):
    result = []
    i = j = 0
    while i < len(a) and j < len(b):
        if a[i] <= b[j]:
            result.append(a[i])
            i += 1
        else:
            result.append(b[j])
            j += 1
    result.extend(a[i:])
    result.extend(b[j:])
    return result

Time complexity: O(n + m)
Space complexity: O(n + m)

Justify: Every element from both arrays is processed once, and the new result list stores all elements from both arrays.

SNIPPET 18 — Flatten Matrix


Code:

def flatten(matrix):
    flat = []
    for row in matrix:
        for val in row:
            flat.append(val)
    return flat

Time complexity: O(mn)
Space complexity: O(mn)

Justify: Every one of the m × n elements is visited and copied into the new flat list.


SNIPPET 19 — Recursive Power


Code:

def power(base, exp):
    if exp == 0:
        return 1
    return base * power(base, exp - 1)

Time complexity: O(exp)
Space complexity: O(exp)

Justify: The exponent decreases by 1 in every recursive call, resulting in exp calls and a recursion stack of depth exp.

Note: If n represents the exponent, this is O(n) time and O(n) space.


SNIPPET 20 — Fast Power


Code:

def fast_power(base, exp):
    if exp == 0:
        return 1
    half = fast_power(base, exp // 2)
    if exp % 2 == 0:
        return half * half
    return half * half * base

Time complexity: O(log exp)
Space complexity: O(log exp)

Justify: The exponent is divided by 2 on every recursive call, resulting in logarithmic calls and logarithmic recursion depth.


SNIPPET 21 — Common Element


Code:

def has_common_element(a, b):
    for x in a:
        for y in b:
            if x == y:
                return True
    return False

Time complexity: O(n × m)
Space complexity: O(1)

Justify: In the worst case, every element of a is compared with every element of b, requiring n × m comparisons.


SNIPPET 22 — Frequency Map


Code:

def build_frequency_map(arr):
    freq = {}
    for val in arr:
        freq[val] = freq.get(val, 0) + 1
    return freq

Time complexity: O(n) average
Space complexity: O(n)

Justify: Each element is processed once and dictionary operations are O(1) on average; the dictionary can store up to n distinct values.
