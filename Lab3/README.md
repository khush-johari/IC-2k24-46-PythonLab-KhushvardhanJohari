## Overview
This lab is designed to help you practice identifying the **time complexity** and **space complexity** of code snippets using **Big-O notation**. You'll work through 22 short Python functions, ranging from simple loops to recursive algorithms, and reason about how their runtime and memory usage scale with input size.
