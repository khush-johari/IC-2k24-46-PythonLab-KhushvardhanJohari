## 1. Square Pattern

**File:** `square.py`

**Aim:** Display a square pattern using Python.

**Logic:**

The program uses nested loops to print the required number of rows and columns.

The outer loop controls the rows, while the inner loop prints the elements in each row.

**Sample Input / Output:**

```text

*  *  *  *  *
```
